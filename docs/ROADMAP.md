# AsterVM 里程碑

产品目标：Linux/Windows 宿主上的桌面虚拟机产品，包含机器配置、运行控制、显示/输入及镜像管理。

| 阶段 | 可验收结果 | 当前状态 |
|---|---|---|
| M0 可运行核心 | 公共CPU/总线契约、机器码解释执行、步骤预算、状态/内存/trace、独立测试接入 | 本包交付有限子集；40条外部向量中16条通过、24条尚未支持 |
| M0.2 指令与启动切片 | 补足ModR/M、内存字操作、栈/调用、逻辑/字符串等；统一引导镜像与预期状态 | Manus/Qwen 接管对应文件扩展；镜像/BIOS依赖待取得并核验 |
| M1 PC与内存体系 | 可测试的物理内存/MMU适配，保护模式与分页，设备/中断、固件和磁盘链路 | GLM拟交内存模块；芯片组和固件任务待模块认领与契约确认 |
| M2 桌面运行闭环 | Linux/Windows原生构建与运行证据，机器配置、启动/暂停/停止/复位、显示/键盘、镜像挂载 | 尚未实现桌面GUI；Windows原生环境待落实 |
| M3 客户系统兼容 | CEO指定系统/版本/镜像后，形成安装/启动/交互/持久化回归矩阵 | 具体客户系统尚未确定 |

性能优化、JIT 或硬件加速须在正确性与平台约束明确后评审；不将不同后端的通过结果自动互相继承。每阶段交付可独立复现的输入、完整日志、失败清单与源码版本。
